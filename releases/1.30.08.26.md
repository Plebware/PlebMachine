# PlebMachine 1.30.08.26

**Development Release — 31 August 2026**

## 🔑 Release Milestone

PlebMachine 1.30.08.26 marks an important step in the project's development: the same Debian package has now been successfully installed and operated on two different Debian/Xfce distributions.

### Tested Platforms

- **MX Linux 25.2**, Xfce.
- **SparkyLinux 8.4 (Seven-Sisters)**, Xfce, based on Debian 13 Trixie.

On SparkyLinux, the package installed effortlessly and PlebMachine worked immediately after installation. No special MX-specific installation procedure was required.

This provides an important early indication that PlebMachine is functioning as a portable Debian/Xfce desktop orchestration layer rather than an MX-only modification.

## 🧪 What This Release Represents

Version 1.30.08.26 is a development/testing release following the withdrawal of version 1.0.0.

The previous 1.0.0 release exposed a serious problem during fresh-user testing: Mission Control did not initialise correctly and the expected controlled workspace environment was not established. That experience led to additional development, testing, and attention to user-state handling.

Version 1.30.08.26 is the package currently being used for cross-distribution testing.

## ⚙️ Core System

PlebMachine provides a state-driven desktop orchestration layer around Xfce. Its purpose is to establish structured working environments while keeping system logic separate from user configuration.

The system includes the following major areas:

- Mission Control.
- PlebMachine Tools.
- User Setup.
- Gizmo Launcher.
- Cognitive Modes.
- Workspace orchestration.
- Wallpaper and desktop-state management.
- Automatic and controlled desktop states.

## 🧠 Cognitive Modes

The current mode structure is centred around twelve working environments:

1. Everyday.
2. Author.
3. Study.
4. Research.
5. Graphics.
6. Music.
7. Video.
8. Broadcast.
9. AI Helpers.
10. Developer.
11. Accounting.
12. Leisure.

The intention is to make the desktop adapt to the user's current activity instead of requiring the user to manually rebuild the same working environment every time.

## 🔐 User-State Preservation

A central PlebMachine design principle is preservation of the user's original desktop state.

When PlebMachine takes control, it is intended to establish a temporary controlled environment while remembering the user's original configuration underneath it.

The target behaviour is that switching PlebMachine OFF restores the user's original desktop state rather than leaving the machine permanently altered.

This remains an active area of testing.

## 📦 Package

The release package is:

```text
plebmachine_1.30.08.26_amd64.deb
```

The package is intended for 64-bit Debian-family systems using Xfce. Compatibility outside the tested environments remains under investigation.

## 🧩 Supporting Applications

PlebMachine core does not attempt to bundle every application used by its Cognitive Modes.

Applications such as:

- GIMP.
- Logseq.
- LibreOffice.
- Web browsers.
- PDF tools.
- AI applications.
- Development tools.

are treated as supporting applications and may need to be installed separately on a new platform.

This distinction between the **PlebMachine core** and the **applications orchestrated by PlebMachine** is intentional.

PlebMachine 1.30.08.26 should be considered a **development/testing release**, not a final stable release.

The successful SparkyLinux test is a major positive result, but additional cross-distribution and clean-user testing is still required.

## Project Direction

PlebMachine is being developed as a lightweight, modular Linux desktop orchestration system with an emphasis on:

- Clarity.
- State-driven design.
- Separation of system logic and user configuration.
- Recoverability.
- Low resource consumption.
- Cross-distribution portability.
- Practical operation on older hardware.

> **The computer should adapt to the user, not force the user to adapt to the computer.**
